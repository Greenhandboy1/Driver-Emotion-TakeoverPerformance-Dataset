# Driver-Emotion-TakeoverPerformance-Dataset

This repository provides the dataset associated with the study:

"Predicting Driver Takeover Performance under the Influence of Emotion Using Millimeter-Wave Radar"

## Dataset Description

The complete dataset was collected from 20 participants.

At the current stage, data from 15 of the 20 participants (75% of the complete dataset) are publicly available in this repository.

The publicly available data include both processed data and raw data.

## Processed Data

The processed dataset contains 360 samples from 15 participants. (file : Features-emotion-TOP.xlsx)

Each sample includes:

- 37 heart rate features
- Emotion label
- Comprehensive takeover performance calculated using the Entropy Weight Method

## Raw Data

The raw dataset contains 60 samples from the same 15 participants.

Each sample includes:

- Raw heart rate data (folder : HeartRate)
- Subjective emotion questionnaire scores (file : Questionnaire score.xlsx)
- Individual takeover performance measures (file : TOP indicators.xlsx)
